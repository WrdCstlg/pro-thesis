Note for anyone comparing against OBS-LIVE-001: that bundle names image
`sha256:e995c7ec…` for its run 4. That image no longer exists. The Docker
content store was destroyed by a disk-exhaustion event on 2026-09-17 and these
images were rebuilt from the same Dockerfile on 2026-09-19, producing a
different image ID — Docker builds are not bit-reproducible. The earlier
digest is therefore a permanently dangling reference: it still records
truthfully what ran, but nothing can resolve it any more.
