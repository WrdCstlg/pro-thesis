# OBS-LIVE-001 — OS-level exit-code measurements

The harness self-reports its verdict ("FAIL (exit 1)"), but self-report is a
claim; these are the OS-level exit codes measured by the observer's shell at
the time of each execution. They were captured in the launching shell's
output stream, which is why the per-run harness logs do not contain them —
this file is the bundle's record of the measurement.

| Run | Command (suffix)                         | Measured exit code |
|-----|------------------------------------------|--------------------|
| 1   | --profile linear --seed 1 --fault ...    | not captured (wrapper expanded $LASTEXITCODE before PowerShell ran) |
| 2   | --profile linear --fault ...             | 1 |
| 3   | --profile linear --seed 1 --fault ...    | 1 |
| 4   | --profile linear --seed 1 --fault ...    | 1 |

Runs 2–4 were launched as `$out = & thesis.exe ...; $code = $LASTEXITCODE`
and the captured value printed by the wrapper; the values above are what the
wrapper emitted. Run 1's exit code was never measured; its FAIL verdict is
harness-self-reported.
